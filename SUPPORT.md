# Support

- **Questions and usage help:** GitHub Discussions of this repository.
- **Bugs and feature requests:** GitHub Issues, using the templates. Please include the TwinCAT
  build, the tool name and the relevant lines from `%LOCALAPPDATA%\ptc-xae-mcp\*.log`, with
  customer names and internal network details removed.
- **Security vulnerabilities:** never in a public issue; see [SECURITY.md](SECURITY.md).
- **Professional support, integration, or introducing AI-assisted engineering in your team:**
  Pneutronic AG (PTC) offers these as a service, https://www.pneutronic.ch.

This is an open-source project maintained alongside day-to-day engineering work. Issues are
triaged regularly, but there is no guaranteed response time.
