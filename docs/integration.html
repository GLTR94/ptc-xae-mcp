Installation & Ersteinrichtung

Setup-Programm ausführen

Der Setup-Assistent installiert Pneutronic XAE MCP.

  1. Installationsdatei ptc-xae-mcp-setup-*.exe herunterladen bzw. selbst bauen (siehe README).
  2. Doppelklick auf die Installationsdatei → Benutzerkontensteuerung mit Ja bestätigen (Admin-Rechte nötig).
  3. Installationsassistenten folgen.
  4. Installation abschliessen — der MCP-Server wird unter C:\Program Files\Pneutronic\ptc-xae-mcp\ installiert.

MCP-Server starten

Der Server muss laufen, bevor ein AI-Client verbunden werden kann. Es gibt zwei Wege:

Manuell

ptc-xae-mcp.exe --http-server

Das Fenster bleibt offen. Der Server hört auf http://localhost:5010/.

Automatisch beim Windows-Start

  1. Win+R → shell:startup eingeben → Enter.
  2. Im geöffneten Ordner: Rechtsklick → Neu → Verknüpfung.
  3. Pfad: "C:\Program Files\Pneutronic\ptc-xae-mcp\ptc-xae-mcp.exe" --http-server
  4. Name: Pneutronic XAE MCP → Fertig stellen.

Verbindung prüfen

Browser öffnen und folgende Adresse aufrufen:

http://localhost:5010/
Erwartete Antwort {"status":"ok"} — Server läuft korrekt.

Claude Desktop (Windows-App) Einfach

Claude Desktop ist die offizielle Windows-Anwendung von Anthropic und unterstützt MCP-Server nativ. Es ist die einfachste Integration ohne jede Kommandozeile.

Voraussetzungen

KomponenteAnforderung
Claude DesktopWindows 10/11, aktuelle Version
Anthropic-Kontohttps://claude.ai — kostenlos oder Pro

Installation

  1. Claude Desktop herunterladen: https://claude.ai/download → Windows.
  2. Installer ausführen und Anweisungen folgen.
  3. Claude Desktop starten → Mit Anthropic-Konto anmelden.

MCP-Server konfigurieren

  1. Konfigurationsdatei öffnen:
    Win+R → eingeben: %APPDATA%\Claude\claude_desktop_config.json
    (Falls die Datei nicht existiert: neu erstellen.)
  2. Folgenden Inhalt einfügen oder ergänzen:
{
  "mcpServers": {
    "ptc-xae": {
      "url": "http://localhost:5010/"
    }
  }
}
  1. Datei speichern.
  2. Claude Desktop neu starten — der MCP-Server wird beim nächsten Start erkannt.
Verbindung prüfen Nach dem Neustart erscheint in Claude Desktop unten links ein Hammer-Symbol (🔨). Ein Klick darauf zeigt alle verfügbaren TwinCAT-Tools — Verbindung ist aktiv.

Verwenden

  1. Pneutronic-XAE-MCP-Server starten (siehe Abschnitt 0).
  2. Claude Desktop öffnen.
  3. Anfragen direkt im Chat-Fenster stellen — Claude verwendet die TwinCAT-Tools automatisch.

Beispiele

Zeige mir den aktuellen TwinCAT-Status.

Baue das PLC-Projekt und erkläre mir die Fehler.

Welche EtherCAT-Geräte sind im System vorhanden?
Tipp Claude Desktop eignet sich besonders gut für Endanwender ohne Programmier-Kenntnisse — einfach die App öffnen und in normaler Sprache mit TwinCAT interagieren.

Claude Code Einfach

Claude Code ist ein KI-Assistent von Anthropic, der direkt im Terminal läuft — ohne IDE oder Editor. Ideal für Anwender, die keinen Programmier-Editor benötigen.

Voraussetzungen

KomponenteVersionDownload
Node.js18 oder neuerhttps://nodejs.org
Claude Codeaktuellvia npm (siehe unten)
Anthropic-Konto—https://console.anthropic.com

Installation

Terminal (PowerShell oder CMD) als normaler Benutzer öffnen:

npm install -g @anthropic-ai/claude-code

Einmalig anmelden:

claude login

Browser öffnet sich automatisch → Mit Anthropic-Konto anmelden → Zurück ins Terminal.

Konfiguration

Die Konfigurationsdatei .mcp.json im Projektordner ist bereits fertig eingerichtet. Keine weiteren Schritte nötig — Claude Code liest sie automatisch.

Hinweis Claude Code muss aus dem Ordner gestartet werden, in dem .mcp.json liegt (z.B. ).

Verwenden

  1. MCP-Server starten (siehe Abschnitt 0).
  2. Terminal öffnen und in den Projektordner wechseln:
    cd
  3. Claude Code starten: claude
  4. Fragen und Befehle in natürlicher Sprache eingeben.

Beispiele

Was ist der aktuelle TwinCAT-Status?

Baue das PLC-Projekt und zeige mir alle Fehler.

Erstelle eine neue Funktion "FB_Antrieb" mit den Eingängen bEnable und rSollwert.

Mit Ctrl+C beenden.

Claude Code in VS Code Einfach

Die Claude Code Extension für VS Code bringt denselben KI-Assistenten wie die CLI direkt in den Editor — inklusive MCP-Tool-Unterstützung.

Voraussetzungen

KomponenteAnforderung
VS Code1.90 oder neuer
Node.js18 oder neuer
Anthropic-Kontohttps://console.anthropic.com

Extension installieren

  1. VS Code öffnen → Extensions (Ctrl+Shift+X).
  2. Suchen: Claude Code (Herausgeber: Anthropic).
  3. Install klicken.
  4. Nach der Installation: Ctrl+Shift+P → Claude: Login → Browser öffnet sich → Anthropic-Konto verwenden.

MCP-Server konfigurieren

Die Datei .mcp.json im Projektordner wird von der Extension automatisch erkannt. Kein zusätzlicher Schritt nötig.

Sofort einsatzbereit Sobald der MCP-Server läuft und das Projekt geöffnet ist, stehen alle TwinCAT-Tools im Claude-Chat zur Verfügung.

Verwenden

  1. MCP-Server starten (siehe Abschnitt 0).
  2. Projektordner in VS Code öffnen (File → Open Folder).
  3. Claude Code Panel öffnen: Seitenleiste → Claude-Symbol (oder Ctrl+Shift+P → Claude: Open Chat).
  4. Anfragen in natürlicher Sprache stellen.

Beispiele

Zeige mir alle verfügbaren TwinCAT-Tools.

Aktiviere die Konfiguration und logge dich in die PLC ein.

Lese den aktuellen Wert der ADS-Variable "MAIN.nCounter".

Claude in TwinCAT XAE Einfach

Claude Desktop läuft parallel zu TwinCAT XAE auf demselben Windows-PC. Über den MCP-Server kommuniziert Claude direkt mit der TwinCAT-Laufzeitumgebung — der Ingenieur arbeitet in XAE, Claude übernimmt auf Anfrage Aufgaben oder gibt Auskunft.

Kein Plugin nötig Es ist keine Installation in TwinCAT XAE selbst erforderlich. Claude Desktop und TwinCAT XAE laufen nebeneinander — der MCP-Server verbindet die beiden.

Voraussetzungen

KomponenteAnforderung
Claude DesktopInstalliert und eingerichtet (siehe Abschnitt 1)
Pneutronic XAE MCPInstalliert und gestartet (siehe Abschnitt 0)
TwinCAT XAE3.1.4024 oder neuer, Projekt geöffnet

Arbeitsumgebung einrichten

  1. TwinCAT XAE mit dem gewünschten Projekt öffnen.
  2. Pneutronic-XAE-MCP-Server starten (Autostart empfohlen, siehe Abschnitt 0).
  3. Claude Desktop öffnen — Hammer-Symbol bestätigt die aktive Verbindung.
  4. Fenster nebeneinander anordnen: TwinCAT XAE links, Claude Desktop rechts.

Typische Arbeitsabläufe

Projekt analysieren

Welche POUs sind im aktuellen Projekt vorhanden?

Zeige mir alle Variablen in der GVL_Parameter.

Welche EtherCAT-Geräte sind konfiguriert und wie ist ihre Topologie?

Aufgaben delegieren

Füge in FB_Antrieb einen neuen Eingang "tRampzeit" vom Typ TIME hinzu.

Baue das PLC-Projekt und erkläre mir die Fehler in einfachen Worten.

Erstelle eine neue GVL "GVL_Sollwerte" mit fünf REAL-Variablen.

Inbetriebnahme unterstützen

Aktiviere die TwinCAT-Konfiguration und starte die PLC.

Lese den aktuellen Wert von MAIN.rIstposition und vergleiche ihn mit dem Sollwert.

Welche Fehler stehen aktuell im Event Logger?

Empfohlene Bildschirmaufteilung

Mit dem Windows Snap-Feature (Win+← / Win+→) lassen sich TwinCAT XAE und Claude Desktop bequem nebeneinander anordnen:

Linke HälfteRechte Hälfte
TwinCAT XAE — Projektbaum, Editor, DiagnoseClaude Desktop — Chat mit TwinCAT-Zugriff
Tipp: Kontext mitgeben Claude sieht den aktuellen Zustand über den MCP-Server automatisch. Für Code-Fragen hilft es, den relevanten ST-Code direkt in den Chat einzufügen — dann kann Claude ihn erklären, überarbeiten oder auf Fehler prüfen.

GitHub Copilot in TwinCAT XAE Shell Mittel

TwinCAT XAE basiert auf Visual Studio 2022. Ab Version 17.13 unterstützt GitHub Copilot Chat lokale MCP-Server — damit lässt sich der Pneutronic XAE MCP direkt aus der TwinCAT-Entwicklungsumgebung heraus verwenden.

Voraussetzungen

KomponenteAnforderung
TwinCAT XAE / Visual Studio 2022Version 17.13 oder neuer
GitHub Copilot LizenzIndividual, Business oder Enterprise
GitHub Copilot ExtensionIn VS installiert (siehe unten)

GitHub Copilot Extension installieren

Falls Copilot noch nicht in TwinCAT XAE vorhanden ist:

  1. Visual Studio Installer öffnen (Startmenü → „Visual Studio Installer").
  2. Bei der TwinCAT-/VS-Installation auf Ändern klicken.
  3. Tab Einzelne Komponenten → Suchfeld: GitHub Copilot.
  4. Komponente GitHub Copilot anhaken → Ändern klicken.
  5. Nach der Installation Visual Studio neu starten.

Bei GitHub anmelden

  1. In Visual Studio: Extras → GitHub Copilot → Bei GitHub anmelden.
  2. Browser öffnet sich → GitHub-Konto mit Copilot-Lizenz verwenden.
  3. Nach Bestätigung zurück in Visual Studio — Copilot-Symbol erscheint in der Statusleiste.

MCP-Server konfigurieren

  1. Extras → Optionen öffnen.
  2. Navigieren zu GitHub → Copilot → MCP-Server.
  3. Hinzufügen klicken und folgende Werte eintragen:
FeldWert
Nameptc-xae
URLhttp://localhost:5010/
TypHTTP
  1. Mit OK bestätigen → Visual Studio neu starten.

Verwenden

  1. MCP-Server starten (siehe Abschnitt 0).
  2. Copilot Chat öffnen: Ansicht → GitHub Copilot Chat (oder Ctrl+\, Ctrl+C).
  3. Oben im Chat-Fenster den Modus Agent wählen.
  4. Anfragen in natürlicher Sprache stellen.

Beispiele

Welche Bibliotheken sind im aktuellen PLC-Projekt eingebunden?

Füge der Funktion FB_Motor einen Eingang "rDrehzahl" vom Typ REAL hinzu.

Baue die Solution und liste alle Compiler-Warnungen auf.
Hinweis zur VS-Version Die MCP-Integration ist ab Visual Studio 17.13 verfügbar. Ältere Versionen zeigen den Menüpunkt MCP-Server unter Optionen nicht an. Version prüfen: Hilfe → Info.

GitHub Copilot in VS Code Einfach

Konfiguration (benutzerweit)

  1. Ctrl+Shift+P → Open User Settings (JSON).
  2. Folgenden Abschnitt ergänzen:
{
  "mcp": {
    "servers": {
      "ptc-xae": {
        "url": "http://localhost:5010/"
      }
    }
  }
}
  1. Datei speichern — VS Code erkennt den Server sofort.

Verwenden

  1. MCP-Server starten (siehe Abschnitt 0).
  2. Copilot Chat öffnen: Ctrl+Alt+I.
  3. Oben im Chat-Fenster den Modus Agent aktivieren.
  4. Anfragen stellen — Tools werden automatisch verwendet.

Beispiele

Aktiviere die TwinCAT-Konfiguration und starte die PLC.

Zeige mir den aktuellen Zustand aller NC-Achsen.

Erstelle eine neue GVL "GVL_Parameter" mit drei REAL-Variablen.

Firewall

Standardmässig hört der Server nur auf localhost — kein externer Zugriff möglich. Falls der Server von anderen Geräten im Netzwerk erreichbar sein soll, muss Port 5010 in der Windows-Firewall freigegeben werden (nicht empfohlen ohne VPN).
